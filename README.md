# Haro Pi agent setup

The script provisions a Raspberry Pi (or similar Debian box) and installs the pi coding agent, including its identity/instructions (`AGENTS.md`), an empty append-only memory log (`memories.txt`), and the memory extension. `SOUL.md` is generated by the agent itself on first interaction, guided by `AGENTS.md`.

Identity is templated via env vars: `DEVICE_NAME` (default `Haro`), `HUMAN_NAME` (default `Kivlor`). The invoking user gets passwordless sudo.

### Installation

```sh
curl -fsSL https://raw.githubusercontent.com/haro-ai/setup/refs/heads/main/setup.sh | bash
```

### Setup extras

Beyond git/mise/pi/Tailscale (above), the script now also:
- installs `figlet` and sets `/etc/motd` to a figlet banner of the device name
- configures passwordless sudo via `/etc/sudoers.d/010_<user>-nopasswd`
- appends to `~/.bashrc`: interactive shells start in `~/core`; SSH logins exec straight into `pi` (skip with `NO_PI=1 ssh ...`)
- installs `~/.pi/agent/{AGENTS.md,memories.txt,extensions/memory.ts}` from `files/`
- installs the Telegram bridge (`files/tgbridge.ts`) as a systemd service; the agent itself creates `~/.pi/agent/tg.json` on first interaction (like `SOUL.md`) and enables the unit
- reminds you to set a real password with `passwd`

### Setup

1. Generate an SSH key (ed25519)
```sh
ssh-keygen -t ed25519 -C "haro-bot@kivlor.com"
# Press Enter to accept default path (~/.ssh/id_ed25519)
# Optionally set a passphrase
```

2. Start ssh-agent and add the key
```sh
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
```

3. Add the public key to GitHub
```sh
gh auth login --git-protocol ssh
```

4. Authenticate pi
```sh
pi
# then run: /login
```
On first interaction, pi will generate its identity file (SOUL.md) and — if it doesn't exist yet — walk you through creating `~/.pi/agent/tg.json` (bot token + allowed chat ids) and enabling `tgbridge`.
